# 新增 T65：規則的實際驗證

日期：2026-11-11。

1. 先完成 AGENTS.md、內容格式、共同模板及 T50 內容，第一次建置產生四頁（首頁、方法、T50、協作規則）。
2. 保存既有模板、首頁模板、樣式、互動、建置工具及 T50 內容的 SHA-256，見 `extension-baseline.json`。
3. 依相同格式新增 `content/cases/t65.json`，填入六段必備內容、六項指標、兩組媒體與來源。T65 素材已在選材階段加入清單。
4. 當下逐檔核對上述既有檔案的 SHA-256，全部保持一致；不複製案例 HTML，不手改首頁或導覽。
5. 第二次建置自動增加 `t65.html`、首頁 T65 項目、所有頁面的 T65 導覽及 T50 的下一篇連結，共五頁。
6. 後續在共同版面驗證時發現 375 px 案例頁的表格最小寬度撐開外層，於共用 CSS 修正 grid 最小寬度。此為兩案例共用的顯示修正，不是新增 T65 所需的特例；其餘擴充基線檔案保持不變。

新增文章只需內容與素材，網站結構可由同一套規則與模板接續產生。數據／圖說的正確性仍需對照研究來源，不能只靠頁面成功產生判定。
