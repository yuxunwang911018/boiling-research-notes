## 發現並修正

初次 375 px 檢查時，兩個案例的表格最小寬度將整頁撐到 434 px。已在共用 CSS 設定 grid 子元素 `min-width: 0`，並讓窄螢幕文章欄使用 `minmax(0, 1fr)`；表格改在自身容器內捲動。修正後重新檢查全部 15 組版面，文件寬度均等於視窗寬度。

## 規則擴充驗證

先完成 T50 與共同模板，再僅新增 T65 內容檔。新增當下九份基線檔案雜湊皆未改變，第二次建置自動新增案例、首頁項目與導覽。後續只有共用 CSS 因上述窄螢幕問題修正，其餘八份基線檔案保持不變。詳見 `extension-log.md` 與 `extension-baseline.json`。

## 驗證邊界

這是網站與研究資料轉錄檢查，不是重新訓練、重算模型誤差或重新執行原生 CFD 驗證。未使用新 test 評分。瀏覽器檢查使用本機 HTTP；內建瀏覽器不支援直接開啟 file 協定，因此未在該瀏覽器自動驗證直接開檔模式。網站本身無 fetch 或伺服器相依功能。

目前沒有 Git 儲存庫、遠端專案、commit／push 或公開部署。素材狀態仍為 `local_preview_only`；公開前的具體內容範圍見 `content-scope.md`。
